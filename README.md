# 尸潮据点

3D 丧尸射击 + 末日据点经营的手机网页游戏。可以"添加到主屏幕"当 App 玩，断网也能玩。

## 玩法

### 📖 主线剧情《启明之殇》（15 关）
原创故事：启明生物用 K-7 病毒做人体实验，前特警林默闯进封锁区寻找妹妹。
- 深夜、手电筒照明、弹药有限（打死丧尸会掉绿色弹药箱）
- 4 种关卡：🔍 搜集物品 · 🛡️ 坚守阵地 · 🆘 营救并护送 · ☠️ 强敌 Boss
- 关卡中有无线电对话，章节之间有过场剧情；通关后同伴加入成为队友

### ☠️ 自由出征（割草）
坚持 5 分钟撤离；升级时三选一技能；第 4 分钟尸王出现，击败它掉落装备。

### 🏗️ 据点与成长
- **建筑**：指挥部、军械库、训练场、医疗站、农场、回收站、宿舍、电台（离线也会产出资源）
- **指挥官等级 + 天赋**：每次出征积累经验，升级获得天赋点
- **武器强化**：每把枪最多 +10
- **装备**：头盔 / 护甲 / 配件，普通到传说 4 档品质
- **队友**：最多带 2 名同伴出征（医疗兵、霰弹手、狙击手、机枪手、科学家），可以升级和训练；队友倒下后靠近 2 秒扶起

## 操作
- 手机：左半屏拖动 = 移动；右半屏拖动 = 手动瞄准（不碰就自动瞄准）
- 电脑：WASD 移动，按住鼠标左键朝鼠标方向开火，Esc 暂停

## 在 iPhone 上安装
1. 用 Safari 打开游戏网址
2. 点底部的「分享」按钮（方框加向上箭头）
3. 选「添加到主屏幕」→「添加」

## 本地运行
```bash
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

## 素材
- 场景道具和贴图：[Poly Haven](https://polyhaven.com)，CC0 授权，详见 [assets/CREDITS.md](assets/CREDITS.md)
- 人物写实模型（Mixamo）**不包含在仓库里**（授权不允许单独分发）。没有模型时游戏自动使用简化的方块人物。
  想在本地用写实人物：登录 Mixamo 后运行 `tools/mixamo_download.mjs` 下载，再运行 `tools/convert_models.mjs` 转换（详见 CLAUDE.md）。
- 3D 引擎：[Three.js](https://threejs.org)（MIT）

## 文件说明
| 文件 | 作用 |
|---|---|
| `js/data.js` | 所有数值（武器、丧尸、建筑、技能、队友、天赋），调平衡改这里 |
| `js/story.js` | 主线剧情（对白、关卡目标、难度） |
| `js/save.js` | 存档、离线产出、升级、成长、结算 |
| `js/battle.js` | 战斗（割草 / 剧情关卡 / 队友 AI） |
| `js/base.js` | 据点 3D 场景 |
| `js/env.js` / `js/models.js` | 写实场景素材 / 人物模型加载 |
| `js/main.js` | 界面和输入 |
| `sw.js` | 离线缓存（发新版时把版本号 +1） |
| `tools/` | 素材转换、自动化测试、平衡模拟 |
