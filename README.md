# 尸潮据点

3D 俯视角丧尸割草射击 + 末日基地经营。手机网页游戏，可以"添加到主屏幕"当 App 玩，断网也能玩。

## 怎么玩

- **出征**：按住屏幕任意位置拖动来移动，角色会自动瞄准开火。坚持 5 分钟就能撤离。
  - 捡蓝色经验球升级，每次升级三选一技能（多重弹、环绕电锯、燃烧瓶……）
  - 捡黄色箱子是物资；红色箱子是医疗包
  - 黄色光柱是求救的幸存者，跟着箭头跑过去就能救回据点
  - 每分钟一波尸潮，第 4 分钟尸王出现
- **据点**：用物资建造和升级 8 种建筑
  - 指挥部决定其他建筑的等级上限
  - 军械库加攻击、解锁新枪；训练场加血；医疗站回血；电台加经验
  - 农场、回收站**离线也会产出**（最多存 8 小时），记得回来收取
  - 用食物招募幸存者，每人加 8% 产量、2% 攻击
- **区域**：郊外小镇 → 废弃商场 → 市立医院 → 军事基地 → 病毒研究所

## 在 iPhone 上安装

1. 用 Safari 打开游戏网址
2. 点底部的「分享」按钮（方框加向上箭头）
3. 选「添加到主屏幕」→「添加」

## 本地运行

```bash
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

电脑上可以用 WASD / 方向键移动，Esc 暂停。

## 文件说明

| 文件 | 作用 |
|---|---|
| `js/data.js` | 所有数值配置（武器、丧尸、建筑、技能），调平衡只改这里 |
| `js/save.js` | 存档、离线产出、升级、结算 |
| `js/battle.js` | 战斗 |
| `js/base.js` | 基地 3D 场景 |
| `js/main.js` | 界面和输入 |
| `sw.js` | 离线缓存（发新版时把版本号 +1） |
| `tools/` | 图标生成、自动化测试 |
